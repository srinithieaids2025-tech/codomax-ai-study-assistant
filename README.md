
# AI Study Assistant

## About
AI Study Assistant is a simple AI-powered application
built using Python, Streamlit and Google Gemini API.

It helps students understand topics, prepare short notes
and practise through quiz questions.

## Features
- Explain topics in simple English
- Summarise study topics
- Generate multiple-choice quiz questions
- Beginner, intermediate and advanced learning levels

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK

## Installation
Install the required libraries:

pip install -r requirements.txt

## API Key Setup
Set your Gemini API key as an environment variable
named GEMINI_API_KEY.

Never upload your API key to GitHub.

## Run the Application
streamlit run app.py
